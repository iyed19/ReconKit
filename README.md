ReconKit is a lightweight Nmap automation tool built in Python to simplify network scanning and reconnaissance tasks.

To install and run it on Linux (Kali/Parrot), first make sure you have Python 3 installed:

sudo apt update
sudo apt install python3 -y


Then clone the repository:

git clone https://github.com/iyed19/ReconKit.git
cd ReconKit


Run the tool using Python:

python3 ReconKit.py
